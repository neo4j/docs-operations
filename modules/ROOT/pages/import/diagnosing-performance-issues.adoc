= Diagnosing performance issues with Java Flight Recorder (JFR)

The `--profile` option runs a JFR recording for the entire duration of the import and captures JVM performance data for analysis.
This option can be especially useful for long running and resource intensive imports.

To use this option, add `--profile` or `--profile=true` to your import command.
For example:

.Run a full import with JFR recording
[source, shell, role=noplay]
----
bin/neo4j-admin database import full \
--nodes=import/movies_header.csv,import/movies.csv \
--nodes=import/actors_header.csv,import/actors.csv \
--relationships=import/roles_header.csv,import/roles.csv \
--profile=true
----

Optionally, you can specify a path where to store the generated Java flight recording using the `--profile-results-path` option.
If not specified, the recording will be stored in the _logs_ folder.
